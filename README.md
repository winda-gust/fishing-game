# 釣り日和 🎣

日本語で遊べる、シンプルなブラウザ魚釣りゲームです。HTML・CSS・JavaScriptで作成しており、ゲーム本体に外部ライブラリ、画像のダウンロード、APIキーは必要ありません。

## 起動方法

### ブラウザで直接開く

リポジトリ内の `index.html` を Chrome、Edge、Firefox、Safari などの最新ブラウザで開いてください。インストール不要で、オフラインでも遊べます。

### 開発用サーバーを使う

Python 3 がある場合、リポジトリのディレクトリで実行します。

```sh
cd fishing-game
python3 -m http.server 8000 --bind 0.0.0.0
```

ブラウザのアドレス欄に `http://localhost:8000` を入力してください。サーバーは `Ctrl+C` で停止できます。Node.js と npm もある場合は、同じディレクトリで `npm start` を使えます。クラウド環境での作業ディレクトリは `/workspace/fishing-game` です。

## 遊び方

1. **「釣りをはじめる」** ボタンを押します。
2. 約1.8秒待つと、ランダムに魚が1匹釣れます。待っている間、開始ボタンは無効になります。
3. 魚の名前と獲得得点が表示され、「本日の釣果」に履歴・匹数・合計得点が追加されます。
4. 繰り返し釣って、全6種類の魚を見つけてみましょう。図鑑には魚ごとの釣れた数も表示されます。
5. **「リセット」** で釣果・得点・図鑑をゼロに戻せます。釣りの途中でもキャンセルできます。

制限時間やゲームオーバーはありません。釣果はページを開いている間だけ保持され、再読み込みするとリセットされます。スマートフォンでも遊べます。キーボードでは `Tab` でボタンを選び、`Enter` またはスペースキーで操作できます。

### 魚と得点

| 魚 | 得点 | 釣れる確率 |
| --- | ---: | ---: |
| アジ | 10 pt | 35% |
| イワシ | 15 pt | 25% |
| サバ | 20 pt | 20% |
| タイ | 50 pt | 12% |
| マグロ | 100 pt | 6% |
| 金の魚 | 300 pt | 2% |

毎回独立して抽選されます。同じ魚も何度でも釣れ、得点は累積します。

## テスト

### ゲームロジック

Node.js 20以上が必要です。外部パッケージをインストールせずに実行できます。

```sh
npm test
```

抽選の境界、6種類の得点、複数回の得点加算、二重開始の防止、リセット、状態の保護などを確認します。

### 実際のブラウザでの操作

ブラウザテストには、開発用依存関係の Playwright と Chromium が必要です。

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

すでに Chromium がインストールされている場合、ブラウザのダウンロードを省略できます。テストは `/usr/bin/chromium` を自動的に使い、ほかの場所にある場合は `CHROMIUM_PATH` で指定できます。

```sh
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

テストは一時的なローカルサーバーを自動で起動し、釣りボタン、6種類の釣果と合計得点、履歴の順序、図鑑、釣り中のリセット、キーボード操作、パソコン・スマートフォンでの表示、JavaScriptエラーの有無を確認します。開発用サーバーを別途起動する必要はありません。

このクラウド環境では Chromium の管理ポリシーが `file://` を制限しているため、実際の画面操作は HTTP 経由で検証しています。同様の制限があるブラウザでは、開発用サーバーを使ってください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 日本語の画面と海辺のSVGイラスト |
| `styles.css` | レイアウト、スマートフォン対応、釣りのアニメーション |
| `game-core.js` | 魚のデータ、抽選、釣果・得点の管理 |
| `app.js` | ボタン操作、待ち時間、画面の更新 |
| `favicon.svg` | ブラウザタブのアイコン |
| `tests/game-core.test.cjs` | Node.js標準テストによるロジック検証 |
| `tests/browser.test.cjs` | Playwrightによるブラウザ操作の検証 |

魚の種類・得点・出現率は `game-core.js` の `FISHES`、待ち時間は `app.js` の `fishingDelay` で定義しています。動きを減らす端末設定に対応し、釣り結果は読み上げ用のライブ領域でも通知します。
